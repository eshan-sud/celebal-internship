# Celebal-Summer-Internship-2025

This repository is a record of my Node.js remote internship at **Celebal Technologies Pvt Ltd** from **20th May 2025 to 20th July 2025**.

- **Week 1**: Installed Node.js & understood basics of Node.
- **Week 2**: Worked with packages like `fs`, `http`, & `path` to create a file management tool that can create, read, & delete files.
- **Week 3**: Refactored async code from callbacks to Promises and Async/Await.
- **Week 4**: Set up an Express server with basic routing and middleware.
- **Week 5**: Implemented MongoDB CRUD operations using Mongoose.
- **Week 6**: Built a RESTful API with authentication and CRUD routes.
- **Week 7**: Added JWT authentication, refresh tokens, and protected routes.
- **Week 8**: Integrated advanced Express features: file upload, error handling, EJS, and WebSocket.

**Final Project**: Restaurant chatbot – [GitHub Link](https://github.com/eshan-sud/dineBot/)
